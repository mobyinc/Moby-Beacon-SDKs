# @moby-beacon/sdk-web

TypeScript/JavaScript SDK for sending events from websites to the Moby Beacon API. Standalone npm package (no workspace); `src/types.ts` holds the API wire types and must stay in sync with the API's `POST /events` contract.

## Commands

- `npm ci` — Install dependencies
- `npm run build` — Bundle to `dist/` (ESM + UMD + declarations)
- `npm run dev` — Watch mode
- `npm test` — Jest
- `npm run lint` / `npm run format:check`
